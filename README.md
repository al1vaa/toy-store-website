# 🌲 Интернет-магазин «BirchBark»

> Полнофункциональный интернет-магазин по продаже изделий из дерева и оказанию столярных услуг. Дипломный проект.

---

## 📌 О проекте

Интернет-магазин «BirchBark» разработан в рамках выпускной квалификационной работы по специальности 09.02.07 «Информационные системы и программирование».

**Основная идея:** создание единой платформы для продажи пиломатериалов, готовых деревянных изделий и столярных услуг (распил, сборка мебели, установка лестниц). Проект решает проблему отсутствия у предприятий деревообработки современного онлайн-канала сбыта и автоматизирует ключевые бизнес-процессы.

## ✨ Функциональные возможности

### Пользовательская часть

| Модуль | Описание |
|--------|----------|
| 🏠 **Главная страница** | Слайдер с услугами (лестницы, распил, сборка мебели), блок акций из базы данных |
| 📂 **Каталог** | Иерархическое боковое меню категорий (рекурсивный обход), сетка товаров, сортировка по названию и цене |
| 🔍 **Поиск** | Полнотекстовый поиск по названию, артикулу, категории. Пагинация (12 товаров на страницу) |
| 🛒 **Корзина** | Добавление товаров через AJAX (без перезагрузки), изменение количества, удаление, подсчёт итогов |
| 📦 **Оформление заказа** | Создание заказа с привязкой к пользователю, сохранение в БД |
| 👤 **Личный кабинет** | Просмотр и редактирование профиля, смена пароля, история заказов |
| ⭐ **Отзывы и рейтинги** | Оценка товара по 5-балльной шкале, сортировка отзывов (по дате, по оценке), пагинация (5 отзывов на страницу) |

### Услуги (модальные окна)

| Услуга | Описание |
|--------|----------|
| 🪚 **Технический распил** | Калькулятор с учётом: тип материала (сосна, дуб, лиственница, фанера и др.), толщина, количество резов, длина заготовок, сложность реза. Минимальная сумма — 3000 руб. |
| 🛋️ **Сборка и установка мебели** | Информационное окно с описанием услуги |
| 🪜 **Установка лестниц** | Информационное окно с описанием услуги |
| 🏢 **Оптовикам** | Условия сотрудничества с юрлицами, форма заявки (сохраняется в БД) |

### Административная панель

| Модуль | Описание |
|--------|----------|
| 📋 **Управление заказами** | Просмотр всех заказов, изменение статуса («Ожидает обработки», «В обработке», «Отправлен», «Доставлен», «Отменён»), добавление комментариев, удаление заказа |
| ➕ **Добавление товара** | Форма с полями: название, категория, производитель, артикул, цена, скидка, характеристики (материал, размеры, цвет, вес), описание, загрузка до 3 фото |
| ✏️ **Редактирование товара** | Изменение всех полей, управление активностью товара, удаление и перезагрузка изображений |
| 👥 **Управление пользователями** | (опционально, если реализовано) |

## 🗄️ Структура базы данных

База данных включает **18 таблиц**, спроектированных по реляционной модели:

| Таблица | Назначение |
|---------|------------|
| `users` | Персональные данные пользователей (ФИО, телефон, адрес) |
| `roles` | Роли (администратор — 777, пользователь — 1111) |
| `usercredentials` | Учётные записи (логин, email, хеш пароля) |
| `usersessions` | Токены для механизма «запомнить меня» (срок 30 дней) |
| `categories` | Иерархическая структура категорий (parent_category_id) |
| `products` | Товары (название, артикул, цена, скидка, описание, активность, средний рейтинг) |
| `manufacturers` | Производители |
| `suppliers` | Поставщики |
| `productspecifications` | Характеристики (материал, размеры, цвет, вес) |
| `galleries` | Изображения товаров (до 3 фото) |
| `carts` | Активная корзина пользователя |
| `cartitems` | Позиции корзины |
| `orders` | Заказы (дата, сумма, способ доставки и оплаты, статус) |
| `orderitems` | Состав заказа на момент оформления |
| `reviews` | Отзывы (оценка 1–5, текст, дата) |
| `promotions` | Акции (заголовок, описание, ссылка, срок действия) |
| `servicerequests` | Заявки на услуги (JSON-поле `details` для параметров расчёта) |
| `contacts` | Обращения из контактной формы |

### Ключевая особенность

Для заявок на услуги используется **JSON-поле `details`**, где сохраняются все параметры калькулятора:
